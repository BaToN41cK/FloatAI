## 📖 Что это такое?

**Неко** — это всегда-под-рукой AI-помощник в виде полупрозрачного безрамочного окна, которое живёт в правом верхнем углу экрана поверх всех приложений. За «девушкой-кошко-девочкой» скрывается полноценный AI-агент:

- 💭 **думает и отвечает** через выбранного AI-провайдера (стриминг, markdown, история диалога);
- 👁 **читает картинки** — присланный скриншот проходит OCR (рус + англ), и Неко решает задание, переводит или отвечает по содержимому;
- 🌐 **выходит в интернет** — сама ищет через Brave Search, открывает страницы и отвечает «с источниками».

### 🎯 Чем полезен на практике?

| Сценарий | Как помогает |
|---|---|
| 📚 **Учёба / домашка** | Скриншот задания → `Ctrl+V` → Неко решает с пояснениями |
| 💻 **Работа с кодом** | Скриншот ошибки / стектрейса → объяснение и исправление |
| 🌍 **Быстрые вопросы** | Погода, курсы, новости — Неко сама найдёт в интернете |
| 🔗 **TL;DR ссылок** | Скинул ссылку — получишь краткое содержание страницы |
| 🖥 **Многозадачность** | Окно поверх всего, не мешает игре/работе; авто-скрытие через 10 мин |
| 🕶 **Приватность** | Окно исключено из захвата экрана (не видно в трансляциях/записи) |

## ✨ Возможности

### 💬 Чат и интеллект
- **AI-провайдеры** — Mistral, OpenAI, Anthropic, Google, GigaChat, YandexGPT, Z.ai, Ollama, LM Studio и свой OpenAI-совместимый API.
- **Z.ai** — модели в списке разделены на платные и бесплатные: `GLM-4.7-Flash`, `GLM-4.5-Flash` и `GLM-4.6V-Flash` помечены как `(free)` согласно официальной таблице цен Z.ai.
- **Маркировка стоимости** — бесплатные модели помечены `(free)`, остальные `(paid)`. Для облачных сервисов бесплатность квот и акций зависит от аккаунта и региона.
- **Локальные модели** — Ollama и LM Studio работают через localhost без API-ключа.
- **Автоопределение модели** — при вводе `gpt-*`, `claude-*`, `gemini-*`, `GigaChat` или `YandexGPT` провайдер определяется автоматически.
- **Markdown-рендеринг** — заголовки, списки, код, таблицы (локальный `marked`, без CDN).
- **Голосовой ввод** — кнопка 🎙: говоришь → Voxtral превращает речь в текст в поле ввода → правишь → отправляешь.
- **Несколько диалогов (сессии)** — переключение и создание новых; история в `logs/history.json`.
- **Компактный контекст** — история ограничивается по бюджету токенов (самые свежие сообщения всегда в промпте) + автоматическая сводка старой истории.
- **Постоянная личность** — `personality.md` подгружается один раз при старте и используется как стабильный system prompt во всех ответах: модель всегда «помнит» характер, а не получает новый фрагмент на каждый запрос (быстрее и стабильнее).
- **Без отдельной памяти Неко** — используется только `config/personality.md` и история диалогов.
- **Отмена генерации** — клавиша `Esc`.
- **Защита от лимитов API** — после ответа `429` приложение временно блокирует повторные запросы, чтобы не расходовать лимит дальше.
- **Индикатор связи** — зелёная/красная точка: сеть и прокси живы/мертвы.
- **Статус поиска** — приложение показывает, когда Неко ищет информацию в интернете.
- **Счётчик токенов** — во время ответа показывает примерное число сгенерированных токенов.
- **Размер шрифта** — настраивается во вкладке «Тема».

### 🧩 Плагины и инструменты

Во вкладке «Прочее» можно отдельно включить или отключить поиск в интернете и чтение найденных страниц.

### 📸 Скриншоты и OCR
- `Win+Shift+S` или **drag&drop** картинки прямо в чат.
- **Tesseract.js** (рус + англ) — распознавание полностью локальное, картинка никуда не отправляется.
- Неко знает **уверенность OCR**: если текст распознался криво — честно попросит скрин чётче, а не будет выдумывать ответ.

Языковые модели OCR поставляются отдельным optional-пакетом, чтобы не раздувать основной установщик:

```powershell
npm run package:ocr
```

Команда создаёт `dist/ocr-lang-data.zip`. Для работы OCR распакуй его так, чтобы файлы `eng.traineddata.gz` и `rus.traineddata.gz` оказались в `app/vendor/lang-data/`.

### 🌐 Доступ в интернет (агентные инструменты)
- **Поиск Brave Search** — HTML-выдача парсится без API-ключа, кэш на 10 минут.
- **Чтение страниц** — вычищает скрипты/стили, отдаёт модели чистый текст (до 4000 символов).
- **Защита**: только публичные http/https (localhost и внутренние сети заблокированы — SSRF-safe) + чёрный список `BLOCKED_SITES`.
- В конце ответа — блок **«Источники»** со ссылками.

### 🪟 Поведение окна
- Прозрачное безрамочное окно поверх всего (`alwaysOnTop`, `skipTaskbar`), стандартный размер — `600×500`.
- При открытии окно возвращается в правый верхний угол экрана.
- Прозрачность меняется через настройки или `Ctrl + колесо мыши` и сохраняется.
- **Авто-скрытие** после 10 минут бездействия (вернуть — `\`).
- **Защита от захвата экрана** (`WDA_EXCLUDEFROMCAPTURE`) — окно не попадает в трансляции и записи (Windows 10 2004+).

### 🐱 Личность
- Характер, стиль речи и правила Неко задаются в **`personality.md`** — это system prompt. Хотите строгого ассистента вместо кошко-девочки — правьте один файл.

## 🚀 Запуск

**Требования:** Windows 10/11, Node.js 18+ и API-ключ выбранного провайдера.

```bash
git clone <repo> && cd Window_Helper
npm install

npm start
```

API-ключ не нужно хранить в файлах проекта: открой настройки приложения, выбери провайдера и вставь ключ. Он сохраняется локально через Windows `safeStorage`.

API-ключ сам по себе обычно не кодирует название модели. Поэтому провайдер и модель выбираются отдельно, а для собственного endpoint модель указывается вручную.

### Запуск без консоли

| Способ | Что делает |
|---|---|
| `start-ai-chat.vbs` | Двойной клик — старт без окна терминала; повторный запуск **не создаёт вторую копию** |
| `start_chat.py` | То же через Python-лаунчер (по желанию) |

## ⚙️ Настройка

Все параметры настраиваются в приложении. В панели доступны провайдер, модель, API-ключ, тема, размер шрифта, прозрачность, плагины, диагностика, прокси, чёрный список сайтов и автозапуск. API-ключ в диагностике не показывается.

### Прокси

Если API сбрасывает соединение, укажите локальный прокси во вкладке «Прочее». Весь трафик AI API, поиск и чтение страниц идёт через `net.fetch` и уважает этот прокси.

### Диагностика

В настройках есть отдельная вкладка «Диагностика». Кнопка копирует сведения о системе, провайдере, модели, endpoint, плагинах и состоянии `safeStorage`, но сам ключ не раскрывает.

### Свой AI-агент

Файл `config/personality.md` не входит в Git: это личный system prompt пользователя. Создай его вручную и опиши, каким должен быть твой агент. Можно начать с такого шаблона:

```markdown
# Мой AI-агент

## Личность

Ты — спокойный и внимательный помощник по имени Астра.
Отвечай на языке пользователя, дружелюбно и без лишней воды.

## Приоритеты инструкций

1. Сначала соблюдай правила безопасности и честно говори, если чего-то не знаешь.
2. Затем отвечай точно и по существу.
3. Для сложных задач объясняй ход решения и приводи короткие примеры.

## Контекст о пользователе

- Пользователь изучает программирование.
- Предпочитает практичные ответы с готовыми примерами кода.
- Не выдумывай личные данные: используй только то, что указано здесь или сказано в текущем диалоге.

## Формат и принципы

- Пиши простым человеческим языком.
- Используй Markdown для списков и кода.
- Не повторяй вопрос пользователя.
- Если запрос неоднозначен, задай один уточняющий вопрос.
```

Замени имя, характер, интересы, язык, формат ответов и контекст на свои. Не добавляй в этот файл API-ключи, пароли и другие секреты. Если файла нет, приложение использует нейтральную личность помощника по умолчанию.

### Упаковка и автообновление (v2.1)

```powershell
npm run dist   # сборка NSIS-установщика и портативного exe в dist\
```

- **electron-builder** пакует приложение в `dist/AI Chat Overlay Setup <версия>.exe` (и unpacked-версию в `dist\win-unpacked`).
- **electron-updater** при запуске проверяет GitHub Releases; скачанное обновление ставится автоматически при выходе (`Ctrl+Shift+Q` — «выйти и обновить»). В статус-строке появляется сообщение «обновление готово».
- `start_chat.py` / `start-ai-chat.vbs` сначала ищут упакованный exe в `dist\`, и только потом dev-режим через `node_modules\electron`.
- Для публикации: соберите `npm run dist`, создайте GitHub Release и загрузите туда `.exe`, `.exe.blockmap` и `latest.yml` из `dist\` — updater подхватит их сам.

### Настройки из окна (v2.1)

Кнопка «⚙» или `Ctrl+O` открывает панель с категориями «Модель», «Персонализация», «Тема», «Диагностика» и «Прочее». Ключ сохраняется в настройках пользователя через Windows `safeStorage`; прокси применяется после перезапуска.

### Данные и логи

- Логи — `logs/app-ГГГГ-ММ-ДД.log`
- История диалогов — `logs/history.json` (формат сессий)
- Позиция/прозрачность окна — `userData/window-state.json` (папка данных приложения)
- Настройки провайдера и зашифрованный ключ — `userData/settings.json`

## 🔒 Приватность и безопасность

- **OCR локальный**: скриншот обрабатывается Tesseract.js на твоей машине, изображение не покидает ПК — модель получает только распознанный текст.
- **SSRF-защита**: Неко не может открыть `localhost` и внутренние адреса (127.x, 10.x, 192.168.x, 172.16–31.x, *.local, *.internal).
- **Чёрный список**: `BLOCKED_SITES` запрещает выбранные домены.
- **Защита от захвата**: окно не видно в записях экрана и трансляциях (Windows 10 2004+).
- ⚠️ Учти: текст сообщений отправляется в Mistral API — не вбивай в чат пароли и секреты.
